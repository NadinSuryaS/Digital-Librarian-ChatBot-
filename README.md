📚 Digital Librarian Chatbot

AI-Powered Book Discovery & Intelligent Library Assistant

The Digital Librarian Chatbot is an AI-powered web application designed to simplify book discovery and enhance the digital library experience. It allows users to search for books, explore summaries, compare titles, and receive personalized recommendations through a natural conversational interface. By integrating Google Gemini AI and the Google Books API, the system delivers intelligent, real-time, and context-aware responses, making book exploration faster, smarter, and more interactive.

🏗️ System Architecture (Overview)

1. User submits a text query through the chatbot or search bar


2. The chatbot processes input using AI (NLP)


3. Google Books API retrieves book metadata


4. Google Gemini AI generates intelligent responses


5. Results are displayed on the webpage in an interactive format

⚙️ Environment Setup

1. Install Node.js and npm


2. Create a React project using Vite

npm create vite@latest digital-librarian --template react


3. Install required dependencies

npm install @google/generative-ai tailwindcss framer-motion


4. Configure Tailwind CSS


5. Add API keys securely


6. Run the development server

npm run dev
